# Notification sound assets

`universfield-new-notification.mp3` is the permanent built-in default notification sound. It is not uploaded to the server. `soundreality-notification.mp3` remains a built-in selectable option.

The app uses these optional MP3 files when present. If a file is missing or the browser blocks playback, it falls back to a short generated tone.

- `soft-bell.mp3`
- `door-bell.mp3`
- `customer-success.mp3`
- `customer-error.mp3`
- `customer-order.mp3`
- `customer-shipped.mp3`
- `admin-alert.mp3`
- `admin-order.mp3`
- `admin-payment.mp3`
- `cash-register.mp3`

Only add audio you created or are licensed to use.
